Introducing Isotropic Level I\mathcal{I}I

We introduce an objective I\mathcal{I}I that measures how close an elasticity tensor is to isotropic behavior. Intuitively, isotropic materials respond identically to deformation in every direction, while anisotropic materials exhibit direction-dependent stiffness. Our metric quantifies this notion by measuring the distance between a given elasticity tensor and the space of isotropic tensors.

Beyond serving as a diagnostic measure, I\mathcal{I}I can also be used as an optimization objective. In topology optimization or microstructure design, minimizing this metric encourages the effective elasticity tensor to approach isotropy. In our recent work, we embed this objective into the design process of homogenization-based microstructures. Under our proposed design space, a CMA-ES optimizer typically converges within roughly 2000 iterations and successfully discovers microstructures whose homogenized elasticity tensors are nearly isotropic.

Kelvin Representation

When computing tensor norms, directly using the Voigt representation leads to incorrect weighting of shear components. To preserve the correct tensor inner product, we use the Kelvin representation.

Define the strain vector in Kelvin form as:

k=[ExxEyyEzz2Eyz2Exz2Exy]k = \begin{bmatrix} E_{xx} \\ E_{yy} \\ E_{zz} \\ \sqrt{2}E_{yz} \\ \sqrt{2}E_{xz} \\ \sqrt{2}E_{xy} \end{bmatrix} k=​Exx​Eyy​Ezz​2​Eyz​2​Exz​2​Exy​​​

With this definition,

kTk=E:Ek^Tk = E:E kTk=E:E

For a fourth-order elasticity tensor, the conversion from Voigt to Kelvin form is

Ck=DCD,C_k = D C D, Ck​=DCD,

where

D=diag⁡(1,1,1,2,2,2).D = \operatorname{diag}(1,1,1,\sqrt{2},\sqrt{2},\sqrt{2}). D=diag(1,1,1,2​,2​,2​).

This transformation ensures that the Frobenius norm of the matrix representation corresponds to the true tensor inner product.

Isotropic Level

The set of isotropic elasticity tensors forms a two-dimensional linear subspace spanned by the volumetric and deviatoric projectors.

Define

u=13[111000]T,\mathbf{u} = \frac{1}{\sqrt{3}} \begin{bmatrix} 1 & 1 & 1 & 0 & 0 & 0 \end{bmatrix}^{T}, u=3​1​[1​1​1​0​0​0​]T,

J=uuT,L=I−J,\mathbf{J} = \mathbf{u}\mathbf{u}^T, \qquad \mathbf{L} = \mathbf{I} - \mathbf{J}, J=uuT,L=I−J,

where I\mathbf{I}I is the 6×66\times66×6 identity matrix. Here J\mathbf{J}J projects onto the volumetric strain direction, while L\mathbf{L}L projects onto the deviatoric (shear) subspace, and the two projectors are orthogonal.

Any isotropic elasticity tensor can therefore be written as

Ciso=3κ J+2μ L,C_{\mathrm{iso}} = 3\kappa\,\mathbf{J} + 2\mu\,\mathbf{L}, Ciso​=3κJ+2μL,

where κ\kappaκ and μ\muμ denote the bulk and shear moduli.

To obtain the isotropic tensor closest to a given elasticity tensor CCC, we project CCC onto this subspace:

Ciso=arg⁡min⁡a,b∥C−aJ−bL∥F2.C_{\mathrm{iso}} = \arg\min_{a,b} \|C - a\mathbf{J} - b\mathbf{L}\|_F^2 . Ciso​=arga,bmin​∥C−aJ−bL∥F2​.

Because J\mathbf{J}J and L\mathbf{L}L are orthogonal, the optimal coefficients are

a=⟨C,J⟩⟨J,J⟩,b=⟨C,L⟩⟨L,L⟩.a = \frac{\langle C,\mathbf{J}\rangle}{\langle \mathbf{J},\mathbf{J}\rangle}, \qquad b = \frac{\langle C,\mathbf{L}\rangle}{\langle \mathbf{L},\mathbf{L}\rangle}. a=⟨J,J⟩⟨C,J⟩​,b=⟨L,L⟩⟨C,L⟩​.

Evaluating the normalization constants ⟨J,J⟩=3\langle J,J\rangle = 3⟨J,J⟩=3 and ⟨L,L⟩=10\langle L,L\rangle = 10⟨L,L⟩=10 yields

κ=tr⁡(JC)3,μ=tr⁡(LC)10.\kappa = \frac{\operatorname{tr}(\mathbf{J}C)}{3}, \qquad \mu = \frac{\operatorname{tr}(\mathbf{L}C)}{10}. κ=3tr(JC)​,μ=10tr(LC)​.

With these coefficients,

Ciso=3κ J+2μ LC_{\mathrm{iso}} = 3\kappa\,\mathbf{J} + 2\mu\,\mathbf{L} Ciso​=3κJ+2μL

is the orthogonal projection of CCC onto the space of isotropic elasticity tensors, and thus the closest isotropic tensor to CCC under the Kelvin/Frobenius inner product.

Isotropic Level Metric:

We define the isotropic level:

I=∥C−Ciso∥∥C∥,\mathcal{I} = \frac{\|C - C_{\mathrm{iso}}\|}{\|C\|}, I=∥C∥∥C−Ciso​∥​,

which measures the normalized distance between the elasticity tensor CCC and its closest isotropic tensor CisoC_{\mathrm{iso}}Ciso​.

Key properties:

  • CisoC_{\mathrm{iso}}Ciso​ is the closest isotropic tensor under the Kelvin/Frobenius norm.
  • The norm is computed after converting tensors to Kelvin representation.
  • The ratio makes the metric scale invariant.

I=0\mathcal{I}=0I=0 indicates a perfectly isotropic tensor, while larger values indicate increasing anisotropy.

Implementation

first, eliminate the numerical error for the current elastic tensor CvC_vCv​ via:

const Mat6 Csym = 0.5f * (C + C.transpose());

then, convert elastic tensor CvC_vCv​ from Voigt to Kevin representation:

Mat6 D = Mat6::Identity();
const float sqrt2 = std::sqrt(2.0f);
D(3, 3) = sqrt2;
D(4, 4) = sqrt2;
D(5, 5) = sqrt2;
const Mat6 Ck = D * Csym * D;

After finish constructing CCC, we then constructing CimgC_{img}Cimg​ using the steps mention in the preview section.

// J = volumetric projector, L = deviatoric projector.
Vec6 u;
u << 1.0f, 1.0f, 1.0f, 0.0f, 0.0f, 0.0f;
u /= std::sqrt(3.0f);

const Mat6 J = u * u.transpose();
const Mat6 I = Mat6::Identity();
const Mat6 L = I - J;

// Closest isotropic tensor in Kelvin form:
// C_iso = 3*kappa*J + 2*mu*L
const float kappa = (J * Ck).trace() / 3.0f;
const float mu = (L * Ck).trace() / 10.0f;
const Mat6 Ck_iso = 3.0f * kappa * J + 2.0f * mu * L;

finally, we calculate the normalized Frobenius distance between CCC and CisoC_{iso}Ciso​ and that will be the isotropic level we want.

// Distance to isotropic subspace.
const float num = (Ck - Ck_iso).norm();
const float den = std::max(Ck.norm(), 1e-12f);

// 0 means perfectly isotropic. Larger means more anisotropic.
auto isotropic_level = num / den;

using Vec6 = Eigen::Matrix<float, 6, 1>;

// Symmetrize numerically first.
const Mat6 Csym = 0.5f * (C + C.transpose());

// Convert Voigt -> Kelvin so Frobenius norm matches tensor inner product.
Mat6 D = Mat6::Identity();
const float sqrt2 = std::sqrt(2.0f);
D(3, 3) = sqrt2;
D(4, 4) = sqrt2;
D(5, 5) = sqrt2;
const Mat6 Ck = D * Csym * D;

// J = volumetric projector, L = deviatoric projector.
Vec6 u;
u << 1.0f, 1.0f, 1.0f, 0.0f, 0.0f, 0.0f;
u /= std::sqrt(3.0f);

const Mat6 J = u * u.transpose();
const Mat6 I = Mat6::Identity();
const Mat6 L = I - J;

// Closest isotropic tensor in Kelvin form:
// C_iso = 3*kappa*J + 2*mu*L
const float kappa = (J * Ck).trace() / 3.0f;
const float mu = (L * Ck).trace() / 10.0f;
const Mat6 Ck_iso = 3.0f * kappa * J + 2.0f * mu * L;

// Distance to isotropic subspace.
const float num = (Ck - Ck_iso).norm();
const float den = std::max(Ck.norm(), 1e-12f);

// 0 means perfectly isotropic. Larger means more anisotropic.
auto isotropic_level = num / den;
